# Poster Graphic Prompt 13: Model Selection & Comparison (Baseline CNN vs MobileNetV3 vs AST)

## Overview
This prompt creates a clean, academic **Model Selection & Comparison** graphic for the project poster, comparing the three evaluated neural network architectures:
1. **Baseline Standard CNN**: 84% Accuracy
2. **MobileNetV3**: 86% Accuracy
3. **Audio Spectrogram Transformer (AST)**: 90% Accuracy (Selected / Best Performing Model)
