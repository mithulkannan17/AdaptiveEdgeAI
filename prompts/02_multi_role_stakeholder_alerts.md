# Poster Graphic Prompt 02: Multi-Role Stakeholder Profiles & Tactical Alert System

## Overview
AuraForest Sentinel features three specialized operational tiers:
1. **Chief Ranger (Strategic Tactical Command)**: Full command authority, CADIE confidence threshold override, audit trails, and multi-unit deployment routing.
2. **Field Ranger (Mobile Tactical Interception)**: High-contrast heads-up tactical mobile alert, silent vibrating notifications, live GPS compass bearing to threat epicenter, audio spectrogram evidence playback.
3. **Public & Forest Border Civilians (Community Early Warning)**: Color-coded wildfire smoke evacuation alert, elephant/predator buffer breach sirens, and emergency safe route maps.
